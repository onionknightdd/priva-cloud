Buttons / Actions

Button, IconButton, TabSwitchButton, ModeSwitchButton, LiveToggleButton, CopyButton and action-menu patterns.

Button

Use for explicit commands. Danger actions still require ConfirmDialog.

IconButton

Use for compact toolbar actions. In React, replace letters with lucide icons at strokeWidth 1.5.

TabSwitchButton

Use for tight tab-like switching where full Tabs would be too large.

ModeSwitchButton

Use for preview/source switching in compact file viewers. Based on the Skill preview control with a smooth active indicator.

LiveToggleButton

Use for live refresh controls in admin/resource views. Status is shown by the 2px left border.

ToggleButton

Use for one local pressed/unpressed tool state. Use Toggle for form settings.

CopyButton
{ "component": "CopyButton", "state": "hover to reveal" }

Hover reveals the action. Click copies and uses the button itself as feedback.

AsyncActionButton

Use for actions with idle, running, success, error, and disabled states.

MenuButton

Use for secondary actions when the primary command should stay visible.

SplitButton

Use when one command has a default path plus adjacent execution variants.

ConfirmActionButton
Type DELETE

Use for dangerous operations. The destructive command stays disabled until the confirmation text matches.

Agent Usage Rules

Use this section before building a new admin or user UI view.

First lookup Check shared before creating UI

Search web/shared/components and this reference before adding a new component.

Styling CSS variables only

Do not hardcode colors. Border radius stays at 4px or less. No box-shadow.

Icons Use lucide-react

All icons use currentColor and strokeWidth 1.5. Prefer symbols over text-only controls.

State coverage Default, hover, focus, disabled, loading, empty, error

If a component can enter one of these states, the reference should show it.

Page Recipes

Reusable combinations an agent should prefer when composing new screens.

Settings page SectionHeader + SettingRow + Toggle/ListInput
  • Use full-width sections, not nested cards.
  • Put actions at row end.
  • Use ConfirmDialog for destructive changes.
Data page Toolbar + DateRangePicker + Table + EmptyState
  • Show skeleton before data loads.
  • Keep filters compact and scan-friendly.
  • Use CopyButton for IDs and paths.
Agent workflow Message flow + CanvasPanel + TaskTree
  • Status uses 2px left border.
  • Tool output goes in CopyableBlock.
  • Approvals use explicit action cards.
Drawer workflow ResizableDrawer + DrawerHeader + FormSection
  • Use for details, file preview, server tools.
  • Keep footer actions stable.
  • Persist width only when the drawer is user-resizable.
